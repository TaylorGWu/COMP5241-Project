# Coursework：教师可控 AI 备课系统实现解析

源码核对日期：2026-10-26。本课程是用于 COMP5241 midterm discussion 的可编辑草稿/问答资料库，不替代要求的1–2页进度摘要与真实分工证据。

核心论点：不是让AI替教师决定，而是让教师可控地完成备课。

## 01 产品故事与当前系统架构
1. 解释教师如何保留对AI备课修改与发布的控制权
2. 沿一次章节生成请求定位前端、API、IR和SQLite各自职责

## 02 L1 Pipeline：从讲义到结构化课件
1. 用输入与输出解释L1六阶段及其实际边界
2. 说明并发、失败隔离与IR校验怎样保住可用草稿

## 03 L2 Agent：先读、提议，再由教师应用
1. 沿工具调用与消息回传解释agent循环，而非把它等同于聊天
2. 用新增第三页案例解释稳定ID、目标约束和proposed patch

## 04 视觉与 Prompt：图从哪里来
1. 分清Mermaid示意图、代码动画和插画占位路径
2. 按阶段定位实际system prompt、动态user prompt及无模型转换

## 05 测试、设计取舍与 Discussion 路线
1. 用真实缺陷及回归测试说明验证比堆功能更重要
2. 区分内部测试、用户证据与尚未完成的基础设施

## 全局事实边界
这是 Coursework 当前教师端的源码核对讲义，不是通用 AI 产品介绍。资料日期2026-10-26。严格区分当前实现、设计目标和演示样例；不要虚构外部访谈、成员贡献、部署状态或实验数值。课程不是正式提交版幻灯片；讲解者须核对、用自己的话改写，且保留1–2页进度摘要和真实分工。只讲本章两个学习目标，规划两个小节、每节5分钟；每节按既有4页教学弧线生成。所有页面用简体中文，保留英文函数名。脚本写明具体源码位置；每页一个判断，不要通用营销话术。架构/流程图用有具体对象和关系的Mermaid，禁止用文生图绘制文字。

当前实现：Next.js -> FastAPI /api/demo -> L1/L2 -> Pydantic IR -> SQLite；IR用于网页预览和PPTX/DOCX确定性导出。当前demo是请求内SSE、单worker，不是已完成ARQ生产队列；当前检索为字符重叠，不是已接pgvector。文字示意图由AI提出Mermaid代码再确定性渲染；request_illustration仍占位，不是已调用图像生成服务。完整视频/跨厂商验证/生产基础设施不得当已完成能力。每次AI改动先proposed，教师apply才生效，发布仍需教师操作。

完整prompt模板和动态构造函数见同目录prompt-source-appendix.md。该附录是源码快照，不是历史请求日志。本课程所有新生成材料均保持非发布状态。
